Program anatomy

How the convention is built: how many sessions it holds, in which formats, and how many people each lists.

Formats come from eShow’s session types for 2024–2027 and from the session code for earlier years: a single letter is a concurrent session, W, MW, AW and SW are workshops, a SIG code is a group meeting, and POS is a poster. eShow also separates individual presentations (one person, 30 minutes) from panels. The older programs mark few roundtables, so that count is low before 2024. 2000–2003 and 2018 have no sessions in the corpus, and the Research Network Forum (code RN) is not counted.
