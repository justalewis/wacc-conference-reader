Groups

The programs give special interest groups, caucuses, standing groups and consortia their own meeting slots. This is a register of the names that held them, from the first convention in the corpus to the latest, with the years each one met.

This lists sessions in the special-interest slots, grouped by the name in the title. It is not an official list of CCCC's groups. A name's kind follows its latest wording, since many SIGs later became standing groups. Some slots held one-off topical discussions, and those appear as single-year entries (hidden unless you ask). Groups that changed names appear under each name unless an alias joins them. No slots appear for 2000–2003 and 2021–2022, and 2018's program used a different layout, so some groups look like they skipped those years.
